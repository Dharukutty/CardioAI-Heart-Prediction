About CardioAI

CardioAI is an MCA final-year project that connects a clean web interface to a real ANN served by a Flask API. This interface contains no model and no prediction logic.

How the ANN works

Inputs pass through hidden layers of weighted connections with activation functions. During training, a loss function measures errors and an optimiser adjusts the weights. For binary classification, the output layer typically produces a value between 0 and 1 that is converted to a class.

Limitations

A model only reflects its training data. The UCI dataset is small and drawn from specific hospitals, so results may not generalise to other people. Model output is not a diagnosis.

Prediction flow

  1. Enter values
  2. Validate in browser
  3. POST JSON to /api/predict
  4. Flask preprocesses and runs the ANN
  5. Response shown unchanged

API contract

The frontend sends one JSON object using the exact dataset column names. The frontend reads common response keys (prediction, probability, message and similar) and shows the raw response so you can adapt it.
